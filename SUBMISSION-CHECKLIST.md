# Submission checklist

## Completed artifact gates

- [x] Main manuscript compiled with IEEEtran and checked at exactly 12 pages.
- [x] Supplement compiled independently.
- [x] At least 40 unique DOI-backed references are rendered and cited by thematic group.
- [x] DOI metadata was matched exactly against retained Crossref responses.
- [x] Every paper table/macro reporting measurements is generated from retained JSON/CSV.
- [x] Strict checker, explicit oracle, deterministic differential tests, tamper tests, and examples pass.
- [x] PDF logs/text/raster/margins and archive safety are audited.
- [x] Public artifact is rerun from a clean extraction.
- [x] External SHA-256 manifest and machine-readable delivery index are generated.

## Must be supplied by the real authors before a non-anonymous submission

- [ ] Author names, affiliations, email addresses, and ORCID identifiers.
- [ ] Corresponding-author designation.
- [ ] Funding and grant identifiers.
- [ ] Acknowledgments and contributor-role statement.
- [ ] Conflict-of-interest and prior-publication disclosures.
- [ ] Data/software repository DOI or archival URL, if the venue requires one.
- [ ] Venue-specific cover letter and suggested/excluded reviewers, if requested.
- [ ] Final confirmation of the live submission portal's page, anonymity, supplementary-material, and artifact-link rules on the day of submission.

No identity, grant, conflict, approval, or repository DOI has been invented in this release. The manuscript remains anonymous.
