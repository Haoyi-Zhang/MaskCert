# Venue and Submission Notes

The distributed source uses the supplied IEEEtran class and produces a 12-page anonymous main manuscript plus a separately compiled supplement. This is an engineering conformance target for the supplied template, not a representation that a journal's live submission portal has accepted the files.

Before an actual submission, the corresponding human author must verify the live venue rules and enter truthful author names, affiliations, ORCID identifiers, funding, conflicts of interest, data/code statements, and any required declarations. These fields are intentionally not invented in this release.

The manuscript is framed as a systems-security artifact with a narrow mathematical contribution: exact, mask-aware certificates for a shared affine permutation and bounded congruence fragments. It does not claim that the underlying CRT, floor-sum, hashing, or affine-permutation primitives are new.
