## Lineage decision

The original brief used the broader name *Permutation-Complete Sharding
Certificates for Stateless Scan Plans*. The recovered research plan records a scientific narrowing to guarded affine
schedule fragments. The incoming six-page manuscript, two-page protocol, proof,
schema, implementation, exact inputs, certificates and retained results all use
that narrower model. The extension manuscript and protocol
keep that same model and add the safe-anchor update theorem, its checker, exact
Boolean encoding and explicitly separated new experiments.
Therefore this is one project with a formal scope narrowing, not two projects.

A later artifact labeled `pcs-v2`, together with an anonymous nine-page
supplement, is not a compatible revision. It lacks the retained model's guards,
epochs, exclusion semantics, and trusted-history/future separation; it also
uses a different unauthorized-target penalty. It is excluded rather than
renamed or merged. No result from that artifact is used to support this paper.
